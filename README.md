# Mobile Massage Concierge

Experimental concierge / booking application for a mobile massage business.

## Current scaffold

- Next.js 15
- React 19
- TypeScript
- Supabase
- Stripe
- Tailwind CSS
- Radix UI components
- Zod validation

## Local development

```bash
npm install
npm run dev
```

Useful checks:

```bash
npm run typecheck
npm run build
```

## Operating boundary

This repository is an application prototype, not a representation that payment, healthcare, privacy, tax, licensing, or other regulated workflows are production-ready.

Before live deployment, verify current requirements for the jurisdictions and business model in use, including payment handling, customer records, privacy, terms, and any massage-establishment / practitioner obligations that apply.

Do not commit API keys, Stripe secrets, Supabase service credentials, customer health information, or other sensitive records.

See `PROJECT-BOUNDARIES.md` for the repository-wide experimental / commercial activation boundary.
